# ChunkUpload — Resumable Large File Upload PoC

A production-grade **Proof of Concept** demonstrating chunked, resumable file uploads with pause/resume support.

```
React (Vite/TS) → Go (Gin) → MinIO (S3 Multipart API)
                      ↕
                   Redis (upload state)
```

---

## Architecture: Three-Stage Protocol

```
Client                          Backend (Go/Gin)              MinIO              Redis
  │                                    │                         │                  │
  │── POST /upload/init ──────────────►│                         │                  │
  │   { fileName, fileSize, mimeType } │                         │                  │
  │                                    │── CreateMultipartUpload ►│                  │
  │                                    │◄── minioUploadID ────────│                  │
  │                                    │── Save(UploadMeta) ──────────────────────► │
  │◄── { uploadId, chunkSize } ────────│                         │                  │
  │                                    │                         │                  │
  │── POST /upload/chunk?... ─────────►│                         │                  │
  │   (raw bytes)                      │── UploadPart ──────────►│                  │
  │                                    │── MarkChunkDone ─────────────────────────► │
  │◄── { chunkIndex, progress } ───────│                         │                  │
  │   (repeat for each chunk)          │                         │                  │
  │                                    │                         │                  │
  │── POST /upload/complete?... ───────►│                         │                  │
  │                                    │── ListParts ───────────►│                  │
  │                                    │── CompleteMultipart ───►│                  │
  │                                    │── Delete(uploadId) ──────────────────────► │
  │◄── { location } ───────────────────│                         │                  │
```

### Resume Flow

```
Browser crash / network loss
         │
         ▼
GET /upload/status?upload_id=xxx
         │
         ▼
{ next_chunk_index: 42, uploaded_chunks: [0..41] }
         │
         ▼
Resume from chunk 42 → no data re-uploaded
```

## Quick Start

### Prerequisites
- Docker + Docker Compose v2
- Node 20+ (local dev)
- Go 1.22+ (local dev)

### 1. Clone & configure

```bash
git clone <repo> chunked-upload && cd chunked-upload
cp .env.example .env   # already provided as .env
```

### 2. Start all services

```bash
docker compose up --build
```

| Service  | URL                           | Notes                    |
|----------|-------------------------------|--------------------------|
| Frontend | http://localhost:5173         | React dev server         |
| Backend  | http://localhost:8080         | Go/Gin                   |
| Swagger  | http://localhost:8080/swagger | OpenAPI docs             |
| MinIO    | http://localhost:9001         | admin / minioadmin123    |
| Redis    | localhost:6379                | password: redisSecret123 |

### 3. Local development (without Docker)

**Backend:**
```bash
cd backend

# Generate Swagger docs (requires swag CLI)
go install github.com/swaggo/swag/cmd/swag@latest
swag init -g cmd/server/main.go -o docs

# Set env
export REDIS_ADDR=localhost:6379
export REDIS_PASSWORD=redisSecret123
export MINIO_ENDPOINT=localhost:9000
export MINIO_ACCESS_KEY=minioadmin
export MINIO_SECRET_KEY=minioadmin123
export ALLOWED_ORIGINS=http://localhost:5173

go run ./cmd/server
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## API Reference

| Method | Path                | Description                            |
|--------|---------------------|----------------------------------------|
| POST   | `/api/v1/upload/init`    | Stage 1 – initialise session      |
| POST   | `/api/v1/upload/chunk`   | Stage 2 – upload one chunk        |
| POST   | `/api/v1/upload/complete`| Stage 3 – finalise & merge        |
| GET    | `/api/v1/upload/status`  | Resume helper – check progress    |
| GET    | `/health`                | Health probe                      |
| GET    | `/swagger/*`             | Swagger UI                        |

## Non-Functional Features

### Security
| Feature | Implementation |
|---------|---------------|
| Rate limiting | Token bucket per IP: 100 req/min (general), 60 req/min (chunk endpoint) |
| File size cap | `MAX_FILE_SIZE_BYTES` env var (default 10 GB), enforced server-side |
| MIME validation | Allow-list in `config.go`, checked before MinIO upload created |
| CORS | Explicit origin allow-list via `ALLOWED_ORIGINS`, never `*` |
| Chunk size cap | `MaxBytesReader` middleware on chunk endpoint |

### Logging (structured, Zap)
Every chunk logs: `timestamp`, `ip`, `upload_id`, `chunk_index`, `chunk_size_bytes`, `duration`

### Resumability
`GET /api/v1/upload/status?upload_id=xxx` returns `next_chunk_index` — the client
skips straight to the first unconfirmed chunk without re-uploading.
